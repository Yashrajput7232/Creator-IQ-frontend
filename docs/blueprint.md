# **App Name**: CreatorIQ Dashboard

## Core Features:

- Cross-Platform Analytics Aggregation: Unifies analytics from Instagram, YouTube, and TikTok, computing engagement rates.
- Content Performance Analyzer: Analyzes post/reel/video performance and recommends content strategies. LLM tool analyzes engagement patterns, hashtags, video length, and posting times to refine content strategy.
- Creator Valuation Engine: Suggests fair pricing for brand deals using LLM and engagement data, and market benchmarking to recommend rates.
- Brand-Readiness Score: Rates creator suitability for sponsorship based on engagement, niche alignment and content consistency.
- Peer Benchmarking: Shows creator position vs similar creators in their niche and region.
- Campaign & Deal Tracker (Lite): Logs brand deals, deadlines, and invoices. Optional AI reminders for deadlines.

## Style Guidelines:

- Primary color: A vibrant violet (#A78BFA) for a modern and intellectual feel.
- Background color: Light, desaturated violet (#F5F3FF). This maintains harmony with the primary color without overwhelming the interface, fitting for a light color scheme.
- Accent color: Analogous blue (#818CF8). Slightly more saturated and darker, it provides a pleasant contrast for interactive elements.
- Headline font: 'Poppins', a geometric sans-serif for a contemporary, fashionable, avant-garde look. Body text: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look.
- Use clean, modern icons to represent data metrics and platform integrations.
- Dashboard layout should be clean and modular, using cards to display key metrics and insights.
- Subtle transitions and animations for loading data and displaying new insights.
